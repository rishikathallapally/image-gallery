# 📸 Visual Diary

Visual Diary is a simple and responsive image gallery website that I created using HTML, CSS, and JavaScript.

The website contains different types of images such as Nature, People, Food, Animals, and Art. I built it to practice frontend development and JavaScript functionality.

## ✨ Features

- Search images
- Filter images by category
- Add images to Favorites ❤️
- Dark Mode 🌙
- Image Lightbox
- Next and Previous image buttons
- Keyboard navigation
- Responsive design for mobile, tablet, and desktop
- Favorites and dark mode are saved using LocalStorage

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

💡 How It Works:

Search:
Users can search for an image using its title or category. The gallery automatically updates based on the search text.

Category Filtering:
Users can select a category to display only images belonging to that category.

Favorites:
Click the heart button on an image to add it to favorites.
Favorite images are stored in the browser using LocalStorage, so they remain saved even after refreshing the page.

Dark Mode:
The dark mode button allows users to switch between light and dark themes.
The selected theme is also saved using LocalStorage.

Lightbox:
Clicking an image opens it in a larger lightbox view.

Users can:

View the selected image
Move to the next image
Move to the previous image
Close the lightbox
Navigate using keyboard arrow keys
